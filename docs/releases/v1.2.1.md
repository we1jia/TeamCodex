# TeamCodex v1.2.1

本次包含启动挂载恢复、Windows 消息转发修复与原生外观优化。

## 更新内容

- 修复无密码房间的消息转发异常；即时调用和轮询兜底共用请求去重。
- 保留启动参数和环境，经确认后恢复挂载；账号或配置在确认期间变化时取消操作，不强杀 Codex。
- 修复注入器退出后的残留连接，以及重复打开、重新挂载与后台版本同步问题。
- 讨论导航、气泡、字体、菜单间距和主题色跟随宿主；输入字号不再误用正文大小，Mac 成员改用苹果图标。
- Windows 排除内置 app-server，避免误报多个桌面实例；只复用 Node.js 20 及以上版本，不覆盖旧系统 Node。
- 主分支推送通过回归后自动递增版本、打包并发布 Release；各安装包与插件版本同步，旧标签不覆盖。

## 升级提醒

- macOS：退出旧 TeamCodex，先备份团队数据再替换 App。旧版数据可能位于 App 内的 `Contents/Resources/app/data`；若使用 `data-directory.txt` 指向外部目录，请保留并恢复该指针。
- Windows：使用 `TeamCodex-Setup.exe` 升级，或下载便携 ZIP。旧 Node 不满足运行要求时，会在 TeamCodex 目录准备独立运行时。
- 插件 ZIP 不替代桌面安装包。安装后若要求重新打开 Codex，请先保存正在执行的任务，再确认操作。

发布流程包含回归、Windows PowerShell 运行时兼容检查和跨平台打包。安装包构建成功不等同于所有 Windows 设备的原生重启与界面交互均已验收。
