# TeamCodex v1.2.0

本次发行包含团队工作区、原生样式优化和挂载修复。

## 更新内容

- 新增知识库、素材库、成员任务看板与工作日历，支持任务审核状态、素材引用和个人资源权限。
- 统一字体、图标、间距与主题颜色，随 Codex 宿主主题调整；改善窄窗口、Windows 标题栏和弹窗布局。
- 修复重启后 Team 入口不显示、旧挂载标记阻止恢复等问题，挂载结果以页面实际回执为准。
- 保留 Windows 无调试端口时经用户确认的启动或重启流程；保护由 Cockpit 管理的实例，不修改 Cockpit 的账号、代理或混合路由配置。
- 修复 macOS ZIP 携带旧 App 的打包问题，DMG 与 ZIP 均构建当前源码并同步版本号。
- Windows 安装器、便携包与插件包同步至 1.2.0，发行包排除本机团队数据和本地数据目录指针。

## 安装与升级

- macOS：下载 `TeamCodex-macOS.dmg`。退出旧 TeamCodex 后，**先确认并备份团队数据到 App 外部，再替换“应用程序”中的 TeamCodex**。旧版默认数据可能位于 `TeamCodex.app/Contents/Resources/app/data`，直接替换整个 App 会移除这份内置数据；请先复制出来。若使用 `data-directory.txt` 指向外部数据目录，也请保留该文件，并在新版 `Contents/Resources/app/` 中恢复它，或通过 `TEAM_CONTEXT_DATA_DIR` 指定同一数据目录。确认数据位置后再打开新版。
- Windows：下载 `TeamCodex-Setup.exe` 安装升级；便携使用可选 `TeamCodex-Windows-arm64-amd64.zip`。
- `TeamCodex-Codex-Plugin.zip` 是插件包，不替代桌面客户端安装包。
- 新版界面脚本会在重新挂载时加载；如提示必须重启 Codex，请先保存当前任务，再按界面确认操作。

发行流水线验证自动化回归、版本一致性及安装包内容。Windows 实机安装和原生窗口交互仍需实际设备验收。
